## Rebuild

```bash
# terminal 1
PYTHONPATH=src python3 -m saboot.webapp --port 8765

# terminal 2
PYTHONPATH=src python3 tools/build_demo_audio_eleven.py
node tools/record_demo.js
bash scripts/build_demo_video.sh
```

Demo voiceover: ElevenLabs neural TTS (George, eleven_multilingual_v2). The app runtime uses no paid APIs. QuickDrop is fictional; all data is synthetic.
